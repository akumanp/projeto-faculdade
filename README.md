# 🔐 Cifra de Vigenère

Este é um projeto simples em **Python** que implementa a **Cifra de Vigenère**, um método clássico de criptografia.

A ideia do programa é permitir que o usuário **criptografe e descriptografe mensagens** usando uma chave fixa, através de um menu no terminal.  
O foco do projeto é **aprendizado**, não segurança real. **Realizei esse projeto junto com 2 colegas da universidade.**

---

## O que o programa faz
- Criptografa mensagens usando a Cifra de Vigenère
- Descriptografa mensagens usando a mesma chave
- Usa um alfabeto estendido (letras, números, acentos e símbolos)
- Limita a mensagem a 128 caracteres
- Salva a mensagem criptografada em um arquivo `.txt`

---

## Tecnologias
- Python 3

---

## Como executar

Você só precisa ter o **Python 3** instalado.
